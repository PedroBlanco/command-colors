# Command & Colors Web

Proyecto no comercial de juego web por turnos para dos personas, inicialmente **Command & Colors: Ancients**, seguido de **Napoleonics**. Partidas síncronas y asíncronas, navegador de escritorio/móvil, estado persistente en servidor y reglas validadas por este.

**Estado:** repositorio inicializado; implementación aún no disponible. La documentación de requisitos, la arquitectura y la planificación se introducirán mediante una solicitud de integración.

**Materiales:** este repositorio no está afiliado a GMT Games. No incluir ilustraciones, cartas, mapas ni transcripciones completas de contenidos protegidos sin revisar los permisos aplicables. Los derechos de terceros corresponden a sus titulares.

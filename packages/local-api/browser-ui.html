Tablero hexagonal de laboratorio (13 × 9)

Selecciona una unidad propia y toca los hexágonos vecinos para trazar el movimiento. Puedes usar también Tabulador y Entrar. Las unidades propias sin mover aparecen resaltadas y, al elegir una, se indican los hexágonos vecinos. Toca un destino lejano libre para sugerir la ruta geométrica más corta entre casillas desocupadas, o un paso anterior para recortar la ruta. Las marcas no garantizan la legalidad de un movimiento: el servidor decide. La ruta solo se envía cuando la confirmas. En combate sintético, toca una unidad rival y pulsa «Solicitar defensa»; no es un ataque reglamentario de Ancients.

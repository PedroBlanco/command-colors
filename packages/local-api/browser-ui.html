Tablero hexagonal de laboratorio (13 × 9)

Selecciona una unidad propia y toca los hexágonos vecinos para trazar el movimiento. Puedes usar también Tabulador y Entrar. Las unidades propias sin mover aparecen resaltadas y, al elegir una, se indican los hexágonos vecinos. Toca un destino lejano libre para sugerir la ruta geométrica más corta entre casillas desocupadas, o un paso anterior para recortar la ruta. Las marcas no garantizan la legalidad de un movimiento: el servidor decide. La ruta solo se envía cuando la confirmas. Durante la asignación de órdenes sintéticas, toca unidades propias para incluirlas o excluirlas y confirma la selección. En combate sintético, toca una unidad rival y pulsa «Solicitar defensa»; el defensor puede elegir después Mantener posición o Evadir en este mismo panel. También puedes jugar una carta de tu propia mano, terminar movimiento, combate o turno según la fase. Usa «Inspeccionar tablero» para consultar unidades, movimientos realizados y distancias hexagonales. Al seleccionar una unidad propia podrás probar su tipo hipotético de Ancients y después tocar un rival para inspeccionar el alcance y la línea de visión considerando únicamente las unidades visibles. En escenarios sintéticos versionados se conoce el terreno y el tipo de tropa, pero aún faltan líderes y reglas completas; ninguna marca autoriza un ataque. En la fase de combate puedes seleccionar atacante y objetivo en el tablero y solicitar una comprobación explícita que no lanza dados ni altera la partida. No son reglas oficiales de Ancients.
